# AI1C Academy — лендинг курса «ИИ-агенты в 1С»

Лендинг образовательного проекта об использовании ИИ-агентов в разработке
на 1С:Предприятие. Сделан на **Streamlit** (лёгкий Python-фреймворк без
отдельного фронтенда) с бэкендом на **SQLite** и собственной авторизацией
пользователей (bcrypt-хеширование паролей).

## Что уже реализовано

- 🎨 Лендинг в духе современных курс-сайтов: хиро, блоки «почему сейчас»,
  «кому подойдёт», «что вы получите», программа курса, тарифы, FAQ, форма
  заявки.
- 🔐 Регистрация и вход пользователей (email + пароль, хеш bcrypt).
- 🗄️ Хранение пользователей и заявок с лендинга в SQLite (`app/data/app.db`).
- 👤 Заглушка личного кабинета — подтверждает, что сессия и БД работают.
- 🧪 Юнит-тесты бэкенда (`tests/test_auth.py`) и ручные проверки через
  `streamlit.testing` (безбраузерные end-to-end тесты).
- 🌐 Готовая конфигурация Apache 2.4 (reverse-proxy) для локального и
  последующего боевого хостинга.

Это MVP «пока что лендинг» — раздел с уроками, оплата и админка не входят
в этот этап и вынесены в раздел «Дальнейшие шаги» ниже.

## Быстрый запуск (проверить результат прямо сейчас)

### Linux / macOS

```bash
cd ai1c-academy
chmod +x run.sh
./run.sh
```

### Windows

```bat
cd ai1c-academy
run.bat
```

Скрипт сам создаст виртуальное окружение, поставит зависимости из
`requirements.txt`, скопирует `.env.example` → `.env` и запустит сервер.
После запуска откройте в браузере:

```
http://127.0.0.1:8501
```

Вы увидите лендинг; кнопки «Войти» / «Начать» ведут на страницы
регистрации и входа, данные сохраняются в `app/data/app.db`.

## Ручной запуск (без скрипта)

```bash
python3 -m venv .venv
. .venv/bin/activate            # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env
streamlit run app/Home.py
```

## Запуск тестов

```bash
pip install pytest
pytest -q
```

## Запуск за Apache 2.4 (локальный сервер)

Подробная инструкция — в [`deploy/apache/README.md`](deploy/apache/README.md).
Коротко: Streamlit — это отдельный сервер (не CGI/WSGI-скрипт), поэтому
Apache настраивается как **reverse-proxy** перед ним, с поддержкой
WebSocket (нужен модуль `mod_proxy_wstunnel` для интерактивности виджетов).

```
Браузер → Apache (80/443) → Streamlit (127.0.0.1:8501) → SQLite (app/data/app.db)
```

## Дальнейшие шаги (не входят в текущий этап)

- Полноценные страницы модулей курса и материалов (сейчас — заглушка кабинета).
- Постоянная сессия между вкладками/перезагрузками страницы (сейчас логин
  живёт в `st.session_state` в рамках одной сессии браузера; для cookie-based
  persistent-логина можно добавить `extra-streamlit-components` или перейти
  на `streamlit-authenticator`).
- Приём оплаты и привязка тарифов к аккаунту.
- Админ-панель для просмотра заявок (`leads`) и пользователей.
- Переход с SQLite на PostgreSQL при росте нагрузки — меняется только
  `app/core/database.py`, остальной код обращается к нему через функции,
  а не напрямую к `sqlite3`.
- HTTPS и боевой домен при переезде на хостинг (см. `deploy/apache/README.md`).
